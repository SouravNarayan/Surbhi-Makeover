# Radiance Beauty Studio — Website

A premium, static beauty-salon website generated by a Python script, hosted
free on GitHub Pages, with a free Google Apps Script backend handling
appointment bookings.

## Project structure

```
salon-website/
├── generate_site.py        # Python/Jinja2 static site generator — run this
├── config.json              # ALL editable content: name, services, prices,
│                             # address, phone, Instagram handle, GAS URL
├── templates/
│   └── index.html.j2        # Page template (Jinja2)
├── static/
│   ├── css/style.css        # Design system + all styling
│   ├── js/main.js           # Nav, scroll animations, booking modal, form logic
│   └── images/               # Gallery photos (replace placeholders)
├── gas/
│   └── Code.gs               # Google Apps Script backend (paste into Apps Script editor)
├── docs/                     # GENERATED — this is what GitHub Pages serves
└── SETUP_GUIDE.md            # Full step-by-step setup instructions — start here
```

## Quick start

```bash
pip install jinja2
python generate_site.py
```

Then open `docs/index.html` in a browser to preview.

**For the full walkthrough (Google Sheet, Apps Script deployment, Instagram
embed, Google Maps, and GitHub Pages), see [`SETUP_GUIDE.md`](./SETUP_GUIDE.md).**

## Editing content

Everything visible on the site — salon name, tagline, services and prices,
address, phone number, business hours, Instagram handle — lives in
`config.json`. Change values there and re-run `generate_site.py`; you should
never need to hand-edit `docs/index.html` directly, since it's regenerated
from the template each time.
